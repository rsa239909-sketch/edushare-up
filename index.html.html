Hướng dẫn thay Firebase Config của bạn

Ứng dụng hiện đang dùng môi trường **Firebase Cloud của hệ thống**. Nếu bạn muốn lưu dữ liệu về **Dự án Firebase riêng** của bạn hoàn toàn:

  1. Vào Firebase Console -> Tạo project miễn phí.
  2. Bật **Firestore Database** và **Authentication (Email/Password & Anonymous)**.
  3. Mở file HTML này bằng Notepad/VS Code, tìm đoạn `firebaseConfig` ở đầu phần script và dán đoạn mã Config của bạn vào.
